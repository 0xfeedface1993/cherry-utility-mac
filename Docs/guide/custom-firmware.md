# 自定义固件（实验性）

> **风险提示**：自定义固件会修改键盘的固件。虽然每一步都有校验，并且可以随时恢复原厂固件，但刷写本身存在风险。只有在了解后果的前提下才使用；这是非官方功能，与 CHERRY 无关。

自定义固件在已知的原厂固件上做字节级的小改动，例如：

- **F 区固定**：Win 和 Mac 模式下都固定为单按触发功能、Fn+F 输出 F1–F12，不再受 Fn Lock 影响；
- **去掉 Ctrl+Fn 切换 Fn Lock**：Fn 紧挨右 Ctrl，按 Ctrl 组合键时容易误触；
- **F1–F12 的功能**：分别设置 Win 模式与 Mac 模式下 F1–F12 触发的功能（亮度、灯效、媒体键等）。

目前适用于 **MX PIXIU 75**（固件 0117）与 **MX PIXIU 75 宝可梦版**（固件 0102）。

## 打开功能

功能默认隐藏。在「设置 › 实验性功能」中确认风险后，设备详情里会出现「自定义固件」分段。需要用 USB 线有线连接，因为固件的读取和写入都走 OTA 接口。

## 使用流程

1. **获取原厂镜像**：从 CHERRY 官方目录下载升级包（校验 MD5），或选择本地升级包。两种方式都会核对原厂镜像的 CRC，并逐处核对每个补丁位置的原始字节。
2. **编辑方案**：新建或复制一个「方案」，按分组选择要修改的功能。修改先进入草稿，保存后才计算生成镜像的 CRC。同一原厂固件可以保存多个方案。
3. **写入**：写入所选方案，或「恢复原厂固件」。写入走与「固件升级」相同的 OTA 路径；键盘重启后读回 CRC，与生成的镜像一致才算成功，并记入写入记录。

页面顶部会识别键盘当前运行的是原厂固件、哪个方案、方案的早期版本，还是未知固件。

## 文件位置

都在 `~/Library/Application Support/CherryUtility/CustomFirmware/`：

| 文件 | 内容 |
|---|---|
| `Variants/*.cherryfirmware` | 方案，每个方案一个 JSON 文件 |
| `flash-history.json` | 写入记录，最多保留 200 条 |
| `Definitions/*.cherryfw` | 你添加的固件定义；ID 相同时覆盖内置定义 |

## 固件定义文件 `.cherryfw`

一个 JSON 描述一个原厂镜像（型号、版本、大小、CRC）以及它可修改的选项。选项可以是带显式补丁的开关或多选，也可以是引用调色板的「功能槽」。加载时会校验偏移、长度、十六进制格式、补丁重叠和保护区（镜像头和 CRC）。新增固件版本或新功能只需要新增或修改定义文件，不用改代码。

内置定义在 [`App/Resources/FirmwareDefinitions/`](../../App/Resources/FirmwareDefinitions/)。`MX_PIXIU75_WIRELESS_0117.cherryfw` 的所有补丁位置都已与官方 0117 镜像逐字节核对；其中「F 区固定」加「去掉 Ctrl+Fn」两项一起生成的镜像（CRC `0x46F8C57A`）已在真机写入并读回。各项功能的行为仍标为实验性。

定义文件的完整格式、PIXIU 75 0117 的固件知识和验证方式见 [自定义固件：实现说明](../dev/custom-firmware.md)。
