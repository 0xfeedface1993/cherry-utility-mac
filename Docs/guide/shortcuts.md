# 快捷指令与 Spotlight（App Intents）

CHERRY Utility 向系统提供 10 个动作（App Intents）：读取键盘状态与电量、切换配置档、设置灯效 / 亮度 / 速度 / 颜色 / 休眠、关闭背光、载入预设。你可以：

- 在**快捷指令** App 里把它们组合成自己的快捷指令，或放进自动化；
- 在 **Spotlight** 里直接运行（macOS 26 起）；
- 让 **Siri** 运行你自建的快捷指令。

动作在 App 进程内执行，与菜单栏、主窗口共用同一个设备通道和写入队列；写入后菜单栏和主窗口立即刷新。固件相关的操作不开放给自动化。

## 准备

1. 把 CHERRY Utility 放在「应用程序」文件夹（`/Applications`）里并至少打开过一次。只有装在「应用程序」里的 App 才会出现在快捷指令的动作库中。
2. 用 USB 线连接键盘。写入配置需要有线连接。
3. 建议打开「设置 › 通用 › 登录时打开」，并关闭「启动时显示主窗口」：系统为执行动作启动 App 时，可能会弹出主窗口。

## 在快捷指令里使用

1. 打开快捷指令 App，新建一个快捷指令。
2. 在右侧动作库选「App › CHERRY Utility」，或者直接搜索「键盘」「配置档」「灯效」。
3. 把动作拖进编辑区，填好参数后运行。

> 每个动作默认「运行时显示」：执行后弹出结果面板，关掉面板之前快捷指令不会继续。把几个动作串成一条快捷指令时，点开动作的选项，关掉「运行时显示」。

这些动作不会出现在「所有快捷指令」或快捷指令中心的列表里，需要在编辑器的动作库中添加。

## 动作一览

「键盘」参数不选时使用唯一连接的键盘；「配置档」参数不选时修改当前配置档。

| 动作 | 参数 | 结果 |
|---|---|---|
| 获取键盘状态 | 键盘 | 「键盘状态」：名称、型号、电量（%）、充电中、连接方式、固件版本、当前配置档、灯效、亮度（0–4）、速度（1–5）、颜色、休眠（秒）、深度休眠（分钟）、摘要。后续动作可以取用其中任意一项 |
| 获取键盘电量 | 键盘 | 电量百分比（整数）。有线型号会报错 |
| 切换配置档 | **配置档**（配置 1 / 2 / 3）、键盘 | 「已切换到配置 2（波纹 · 亮度 全亮）」 |
| 设置灯效 | **灯效**、配置档、键盘 | 「已更新配置 2：灯效 呼吸」 |
| 设置背光亮度 | **亮度**（灭 / 低 / 中 / 高 / 全亮）、配置档、键盘 | 同上 |
| 关闭背光 | 配置档、键盘 | 把亮度设为「灭」 |
| 设置灯效速度 | **速度**（1 / 5 最慢 … 5 / 5 最快）、配置档、键盘 | 同上 |
| 设置灯光颜色 | **颜色**、十六进制颜色（选「自定义颜色」时填，例如 `#FF7200`）、配置档、键盘 | 同上 |
| 设置休眠时间 | 休眠（秒，0 或 30–300）、深度休眠（分钟，0 或 15–300）、配置档、键盘 | 同上；0 为不休眠 |
| 载入灯光预设 | **预设**、配置档、键盘 | 「已把预设「办公」载入配置 2（…）」；来自其他型号的预设会被拒绝 |

**灯效**（16 种，执行时在目标型号的灯效表里查找；该型号没有时会列出可选项）：波纹、光谱、呼吸、霓虹、曲线、折返、放射、扩散、单点亮、常亮、自定义、彩虹雨、RGB常亮、闪电、火焰、对战。PIXIU 75 支持前 11 种，可以用 `cherry effects` 或主窗口查看你的型号。

**颜色**：随机颜色，官方调色板 10 色——红色 `#FF0000`、橙色 `#FF7200`、黄色 `#FFF005`、绿色 `#00D70F`、天蓝 `#0099FF`、蓝色 `#3153FF`、紫色 `#5E01D2`、品红 `#EE00F1`、粉红 `#FF008A`、白色 `#FFFFFF`，或「自定义颜色」加任意 `#RRGGBB`。

## Spotlight 与 App 快捷指令

App 自带 9 条无需设置的「App 快捷指令」，macOS 26 起可以在 Spotlight 里直接输入短语运行。例如：

| 动作 | 可以这样说 / 输入 |
|---|---|
| 键盘状态 | 「CHERRY Utility 键盘状态」「CHERRY Utility 现在是什么灯效」 |
| 键盘电量 | 「CHERRY Utility 键盘电量」「CHERRY Utility 还剩多少电」 |
| 切换配置档 | 「用 CHERRY Utility 切换到配置 2」 |
| 设置灯效 | 「用 CHERRY Utility 把灯效换成呼吸」 |
| 背光亮度 | 「用 CHERRY Utility 把背光调到高」 |
| 关闭背光 | 「用 CHERRY Utility 关闭背光」「CHERRY Utility 关灯」 |
| 灯光颜色 | 「用 CHERRY Utility 把灯光换成橙色」 |
| 灯效速度 | 「用 CHERRY Utility 把灯效速度调到 3」 |
| 载入预设 | 「用 CHERRY Utility 载入预设办公」 |

在 Spotlight 里也可以只输入动作名，例如「切换配置档」，再选择参数。

## Siri

Mac 上的 Siri 不能直接语音触发 App 的动作（这是 macOS 的限制）。可行的做法是：新建一个快捷指令并起一个好记的名字，例如「键盘切到办公」，然后对 Siri 说出这个名字。

Apple Intelligence 版 Siri 目前只开放给特定领域（App Schema）的动作，没有设备控制这一类；想用自然语言控制键盘，可以用 [MCP](mcp.md) 接入 Claude 等 AI 助手。

## 示例

**一键「专注模式」灯光**

1. 切换配置档：配置 1
2. 设置灯效：常亮（关掉「运行时显示」）
3. 设置背光亮度：中（关掉「运行时显示」）

**低电量提醒**

1. 获取键盘电量
2. 如果「键盘电量」小于 20 → 显示通知「键盘电量低」

**晚上自动关灯**

macOS 26 起快捷指令也支持「自动化」：在快捷指令 App 的「自动化」里新建一个按时间触发的自动化（例如每天 23:00），动作选「关闭背光」。

## 常见问题

| 现象 | 处理 |
|---|---|
| 动作库里找不到 CHERRY Utility | 确认 App 在 `/Applications` 中并打开过一次；从 Xcode 或其他位置运行的副本不会出现在动作库 |
| 多步快捷指令卡在第一步 | 关掉动作的「运行时显示」 |
| 「没有连接受支持的 CHERRY 键盘」 | 用 USB 线连接键盘；经接收器无线连接时部分型号只能读取基础信息 |
| 「连接了多把键盘」 | 在动作的「键盘」参数里选择具体的键盘 |
| 「这把键盘正在升级固件」 | 等固件升级完成后再运行 |
| 运行时弹出主窗口 | 打开「登录时打开」，关闭「启动时显示主窗口」，让 App 常驻菜单栏 |

想在脚本里做同样的事，用 [命令行 `cherry`](cli.md)。
